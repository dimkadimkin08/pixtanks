# PixTanks Map Editor

A tool for creating custom maps for PixTanks.

1. Open `pixtanks-map-editor.html` in your browser.
2. Draw tiles and place objects.
3. Don't forget to add player spawn points.
4. Export the map (you will get a JSON file).
5. Create a "Maps" folder in the PixTanks game directory.
6. Put your JSON map file into the "Maps" folder.
7. Launch the game as a host/server — you will be able to create a lobby with your map.
