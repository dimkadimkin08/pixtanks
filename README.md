# PixTanks

A multiplayer top-down tank shooter with PvP and PvE modes.

Switch between multiple tank classes (shotguns, lasers, drills, drones) by respawning, collect gears to upgrade your tank, and battle in a free-for-all arena with bots or in team-based lobby modes like Capture the Flag.

One of my first personal game projects.

- **Platforms:** Windows, Linux
- **Controls:** WASD to move, mouse to aim, LMB/Space to shoot, E to open shop, X to upgrade
- **Play it on itch.io:** https://dimkadimkin08.itch.io/pixtanks
